BIT 2118 SCIENTIFIC COMPUTING

This repository contains the scientific computing practical tasks and individual real world program modifications for tasks 2 to 20.

The practical work covers NumPy arrays, vectorization, floating point arithmetic, matrix algebra, linear systems, Gaussian elimination, iterative methods, eigenvalues, root finding, nonlinear equations, interpolation, curve fitting, numerical differentiation, numerical integration, ordinary differential equations, optimization and Monte Carlo simulation.

Install the required libraries using:

    pip install -r requirements.txt

Run the original practical programs using:

    python code/scientific_computing.py

Run the individual real world modifications using:

    python code/real_world_cases.py

The task explanations and interpretations are in documentation/answers.md.
The separate assumptions, input data, outputs and interpretations for every real world modification are in documentation/real_world_cases.md.
